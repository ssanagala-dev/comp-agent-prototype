How the Skill Fires

"Sales Compensation" — the Slackbot skill

Routing description: Answers a person's compensation questions using their live Salesforce data — commission & payout status, comp-plan & quota, credit & ACV on an order/opp, product/deal eligibility, Spiff visibility & sync, and comp-plan/LOA timing. Retrieves real-time data from Org62 and Spiff via the Sales Agent MCP server — never estimates a number. Creates a support case when a human is needed.

How it's integrated

  • Skill added to Slackbot — appears alongside other skills in the DM.
  • On a comp question, Slackbot invokes the Sales Compensation skill.
  • Skill calls SalesCompensationMCP → Apex → Org62 · Spiff.
  • Returns a grounded answer with the reasoning, plus a source-of-truth disclaimer.

Key principles

  • Ground every answer in live data — never guess a number.
  • Show the reasoning, not just the figure.
  • State data freshness when it's batch-synced (e.g. Spiff).
  • Know its limits — route to a human when data can't answer.

How It Works: Follow Alex's Question

# Sales Agent · comp-questions

Alex Rivera · 3:14 PM
Why am I only getting 50% credit on OPP-88512? Initech, Marketing Cloud Pilot, $120K — shouldn't this be 100%?

⚡ Sales Agent · AGENTFORCE
Pulling OPP-88512 from Compensation Agent…

Initech – Marketing Cloud Pilot · $120K
Per FY27 Product Eligibility Matrix:
• Marketing Cloud is co-sold
• Base AE (you): 25%
• MC Specialist: 75%

Your 50% is the blended credit: Sales Cloud (100%) + Marketing Cloud (25%) = 50% effective.

CORE LOGIC
  • 01 Identify intent — LLM classifies: credit/eligibility for OPP-88512.
  • 02 Retrieve facts — Pulls the opp from Org62; plan + role from EOS.
  • 03 Apply policy — Reasons over FY27 Matrix; blended credit deterministically.
  • 04 Answer — Returns answer with source links + next-step actions.
