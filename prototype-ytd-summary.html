Where the YTD statement fits in the Comp skill

No new UI. It's one more thing the Incentive Comp skill can answer. The answer comes back as text and tables in the DM, and the full statement comes back as a Google Doc link.

The seller experience

  • Discovery: one new line in the skill's opening message ("Your YTD statement"), plus a suggested prompt.
  • Ask: plain language, like "show my YTD statement", "how much have I earned this year?" or "what was clawed back?"
  • Answer in chat: attainment by component and a YTD summary by statement period, using the same Slackbot tables the skill already shows.
  • Full statement: if the seller asks for it, the skill replies with a Google Doc link in the format Srini's team already uses. Slack shows it as a Google Drive link preview.
  • Follow-ups: "why was $8,000 clawed back?" reuses the PPA and audit-comment logic.
